# Proyecto de Pruebas - Vanilla JS

Este repositorio contiene un conjunto de pruebas y experimentos utilizando **JavaScript puro (Vanilla JS)**.  
El objetivo es practicar y experimentar con ideas relacionadas tanto a la **interfaz de usuario (UI/UX)** como a la **lógica del lado del cliente**, sin depender de frameworks o librerías externas.

## ⚠️ Importante

Este **no es un proyecto formal ni serio**.  
Aquí se realizan pruebas, bocetos, fragmentos de código y conceptos en desarrollo.  
El código puede no seguir buenas prácticas o estar en constante cambio.

## Objetivos

- Probar interacciones UI/UX simples sin frameworks.
- Experimentar con lógica de JavaScript puro.
- Explorar conceptos de diseño, animaciones, eventos, formularios, manejo del DOM, etc.
- Servir como espacio de pruebas para ideas rápidas.

## Requisitos

Ninguno especial. Solo necesitas un navegador moderno.
